A travel poster for Orvane, a place that does not exist: a white town on a rocky headland, lantern boats drifting on a teal sea at dusk, and one stone lantern-tower with a spiral stair rising out of the water, its amber lamp lit. The name ORVANE is set large across the sky, and a small line at the foot tells the judge the place was invented for this poster. main.ts (Node 22, no dependencies) checks the PNG and writes it to /output/entry.png. draw_entry.py shows how the poster was finished from the generated scene.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
